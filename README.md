# Igloo-Inspired Website — Proof of Concept

This project is a personal proof of concept exploring whether I can build a polished, immersive web experience inspired by the visual direction of [igloo.inc](https://www.igloo.inc/).

The goal is not to reproduce the original website or present it as an official Igloo product. It is a small, independent experiment demonstrating that I can translate a strong reference into a working front-end concept with a similar sense of atmosphere, interaction, and visual storytelling.

## Purpose

I created this as a lightweight, voluntarily scoped portfolio exercise. Rather than a long-term production build, it is an intentionally rapid exploration that proves the concept can be designed and implemented. It is included on my résumé as evidence of practical front-end experimentation and creative execution.

## What this demonstrates

- Building a modern interactive site with Next.js and React
- Creating an immersive 3D scene with Three.js
- Translating design inspiration into an original implementation
- Combining visual detail, motion, and responsive web structure in a functional prototype
